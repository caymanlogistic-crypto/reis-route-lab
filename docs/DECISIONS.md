# Принятые решения

27.10.2026. Исходный проект пуст. Пользователь разрешил автономную реализацию, субагентов, тестирование и публикацию. Основное требование: не превращать реконструкцию в утверждение о фактической телеметрии.

- Общий ESM сервис работает локально и в Worker; движок не зависит от базы или браузера. SQLite лежит вне исходников; в личном облаке D1/R2, доступ ограничен платформой Sites владельцу.
- Реестр и черновики содержат редакции. UPDATE с ожидаемой редакцией блокирует незаметную перезапись другой вкладкой. Результаты расчётов и файлы неизменяемы, связаны со снимком; неуспешный расчёт не удаляет успешный.
- Фоновая задача привязана к ID рейса и редакции. Повторный запуск той же редакции идемпотентен; ошибку или прерванную попытку можно повторить без дублирования успешных результатов. Локальная остановка сервиса переводит незавершённые задания в interrupted при старте; облако обнаруживает зависшие задания при проверке спустя пять минут.
- Расчёт в UTC, исходное местное время и IANA-пояс сохранены; DST gap отклоняется, fold требует явного смещения. Географическая сетка tz-lookup приблизительная и указана как ограничение.
- Скорость и позиция выводятся из одной интегрируемой модели с ускорением/торможением; случайный шум выключен. Паузы не выдаются за доказанный сон. Учёт непрерывного движения продолжается через проезд опор.
- Синтетическая геометрия разрешена только для фиксированного собственного демопримера. Для реальных точек требуется разрешённый грузовой Router API; при неразрешённой привязке/подъезде возвращается конфликт.
- Предоставленный ключ проверен: Router API403 Invalid key; Maps v3 также403. Серверный секрет сохранён вне Git и в секретах Sites, в браузер не включается. Реальная интеграция остаётся непроверенной до рабочего ключа.
- OOXML формируется потоковым ZIP: меньше памяти для больших треков. Чтение импорта — browser build ExcelJS. XLSX принимается независимым openpyxl; происхождение и UTC остаются обязательными при любом профиле оформления. Формулы из пользовательского текста не исполняются.
- Резервная копия — согласованный снимок записей плюс неизменяемые связанные файлы, контрольные суммы и версия схемы. Перед восстановлением проверяется отдельное staging-пространство и сохраняется предыдущая копия. Ключи исключены.
- Публикация личная: данные не выставляются в открытый доступ. Локальная версия продолжает работать без облачной платформы. Неизвестный клиентский формат/Wialon не блокирует универсальный XLSX.

Источники интеграции: https://yandex.ru/maps-api/docs/router-api/request.html и response.html; условия https://yandex.ru/dev/tariffs/doc/ru/router/terms/. Сверены 27.10.2026.
