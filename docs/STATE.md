Не перезаписывать .env и не создавать новый Site: ID уже закреплён. Секреты и локальные данные в Git не добавлять. Ближайшая необходимая приёмка — реальный truck маршрут и карта после замены/активации ключа.


Инфраструктурные особенности: системный Node24.14.1 аварийно завершает fs.cpSync каталогов на этом Windows. Для упаковки использован штатный пакетировщик Sites под bundled Node24.19.0. Native Git upload обрывался curl55/56; тот же коммит успешно отправлен isomorphic-git через fetch без изменения истории. Публичные runtime API с этого компьютера доступны через существующий HTTPS-прокси пользователя: для Node используется --use-env-proxy; конфиденциальные заголовки только в памяти/stdin, не в исходниках. Служебные локальные помощники исключены из Git в .sites/.


Обновление по прямому указанию пользователя: стандартная автомобильная маршрутизация mode=driving вместо truck. Масса, габариты, прицеп и грузовые ограничения в Router API больше не передаются. Режим явно обозначен в параметрах и снимке маршрута. Прямая проверка предоставленного ключа с mode=driving также вернула403 Invalid key.

Для этого же разрешённого пользователем браузерного использования настроен YANDEX_MAP_KEY в окружении Sites (в исходниках значения нет); браузерный идентификатор API штатно доступен карте через /api/config.
